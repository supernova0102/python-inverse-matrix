# Python 역행렬 계산 프로그램

행렬식의 여인수 전개와 가우스-조던 소거법으로 같은 정방행렬의 역행렬을 계산하고 비교합니다.

## 실행

Python 3 표준 라이브러리만 사용합니다. 추가 패키지가 필요 없습니다.

```bash
python main.py
```

양의 정수 n을 입력한 뒤 n개의 행을 공백으로 구분하여 입력합니다.

```text
2
23 19
22 30
```

두 방법의 결과:

```text
[  15/136  -19/272 ]
[ -11/136   23/272 ]
```

## 기능

1. 행렬을 행 단위로 입력받아 2차원 리스트에 저장합니다.
2. 소행렬과 여인수로 수반행렬을 구하고 행렬식으로 나누어 역행렬을 계산합니다.
3. 확대행렬 [A | I]에 행 교환, 피벗 정규화, 열 소거를 적용합니다.
4. 두 결과를 출력하고 정확히 일치하는지 비교합니다.
5. 역행렬이 없으면 두 방법 각각 오류 메시지를 출력합니다.

추가로 입력 오류 재입력, 소수·분수의 정확한 계산, 가우스-조던 단계 출력,
원본과 역행렬의 곱이 단위행렬인지 검산, 1×1 행렬 처리를 지원합니다.

## 프로그램 구조

- `input_matrix()`: n과 각 행을 검사하고 `Fraction` 원소의 2차원 리스트를 반환합니다.
- `minor_matrix()`: 지정한 행과 열을 제거합니다.
- `determinant()`: 첫 행의 여인수 전개로 행렬식을 계산합니다.
- `inverse_by_determinant()`: 전치한 여인수 행렬을 행렬식으로 나눕니다.
- `inverse_by_gauss_jordan()`: 확대행렬을 [I | A⁻¹]로 변환합니다.
- `print_matrix()`: 행렬 원소를 정렬하여 출력합니다.
- `multiply()`: A × A⁻¹을 계산합니다.
- `main()`: 입력, 독립적인 두 계산, 예외 처리, 결과 비교, 검산을 연결합니다.

## 테스트

```bash
python test_program.py
```

| 사례 | 행렬 | 예상 결과 |
|---|---|---|
| 숫자 재배열 | `[[23,19],[22,30]]` | det=272, 두 결과 일치 |
| 일반 2×2 | `[[4,7],[2,6]]` | det=10, 두 결과 일치 |
| 행 교환 3×3 | `[[0,2,1],[1,1,0],[2,0,1]]` | det=-4, 행 교환 후 성공 |
| 특이행렬 | `[[1,2],[2,4]]` | det=0, 두 방법 모두 오류 |
| 1×1 | `[[5]]` | 역행렬 `[[1/5]]` |
| 오류 복구·분수 | 잘못된 입력 후 `[[0.5,0],[0,2/3]]` | 재입력 후 역행렬 `[[2,0],[0,3/2]]` |

테스트는 실제 콘솔 프로그램을 6회 실행하고 출력 메시지와 검산 결과를 확인합니다.
알려진 정답, 원본 보존, 각 함수의 특이행렬 예외도 별도로 검사합니다.

## 계산량

재귀적 여인수 전개는 큰 행렬에서 느리므로 학습용 소규모 행렬에 적합합니다.
가우스-조던 소거법은 더 큰 행렬을 계산할 때 유리합니다.
